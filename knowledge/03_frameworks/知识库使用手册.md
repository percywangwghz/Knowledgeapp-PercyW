# 知识库使用手册

> 一级投研知识库 · 新用户三分钟上手
> 核心动作就三个：拖文件、跑评审、刷雷达

## 这是什么

一个会"自己长"的投研知识库。你丢资料进去，AI 负责分类、按研究框架整理成结构化文档；项目可以走「评审 → Battle」流水线；市场侧有雷达自动盯主题信号和叙事变化。两条线：

- **文档线**：文件归档 → 新项目评审 → Thesis Battle → 写回知识库
- **认知线**：Radar（自动抓取 + 公众号）→ 信号池 → 主题叙事/边际变量 → 周报

所有产出物都写回知识库，成为下一步的输入——越用越厚。

## 30 秒上手

1. **左侧栏**是导航：首页 / Thesis Battle / Investment Radar / 新项目评审 / 文件归档，下面按分类浏览全部文档
2. **顶部搜索框**全文检索（项目名、赛道、概念都行）
3. 最常用动作：点「📥 文件归档」，把 PDF 拖进去 → 开始分析 → 确认分类 → 入库，完事

## 功能逐个说

### 📥 文件归档（最常用）

1. 拖入 PDF / DOCX / TXT / MD（可多选）→ 点「开始分析」——**后台执行**，可以随便切页面，进度实时显示
2. AI 做两件事：判断属于 9 个分类中的哪个 + 按该分类的研究框架整理：
   - 行业报告 → 行业总文档框架（产业链全景、投资判断框架、关键变量…）
   - 项目 BP → 项目解剖框架（投资逻辑链、假设树、风险矩阵…）
   - 基金材料 → 机构投资心智模型框架（九模块 + 两附录）
   - 其他 → 通用结构化整理
3. 分析完每个文件一张卡片：AI 提议的分类**可以手动改**（改了会自动按新框架重新整理）→ 点「确认入库」
4. 入库后如果归到了「项目解剖」，卡片下会出现「🧭 发起评审」按钮，一键进入评审流程

注意：扫描件 PDF（纯图片）提不出文字，需要先 OCR；单文件最多读前 15000 字。

### 🧭 新项目评审

用「行业总文档」当认知底座，给新项目做结构化评审：

1. 选择项目 + 行业总文档（从归档跳过来会自动选好，行业也会自动匹配；页面下方就是行业认知卡片可对照）
2. 点「AI 生成评审草稿」→ 草稿出来后可以编辑
3. 点「确认写入两个文档」：项目文档追加评审节，行业总文档同步更新关键变量演进表 / 项目落位表 / 评审留档
4. 写完出现「⚔️ 对该文档发起 Battle」按钮，一键进入红队环节

### ⚔️ Thesis Battle

AI 扮演投委会红队，攻击文档里的观点——不证明你对，只找你什么时候会错：

1. 选一篇文档（从评审跳过来会自动选好），可以点「让 AI 先开火」
2. 你防守、补充、争论；对话自动保存，跨天可以继续
3. 说「今天到这里」或点「结束并写回」→ AI 生成写回预览 → 你确认后才更新文档里的状态表（假设/证伪/置信度）
4. 「中断」= 放弃整场对话，绝不写回文档

### 📡 Investment Radar（五个页签）

- **信息采集**：信号看板 + 手动触发抓取（全量 / 重点主题短跑，后台执行）。平时有定时任务自动跑
- **主题叙事**：各主题当前的市场叙事 + 演变历史（什么事件触发了认知转变）
- **边际变量**：AI 从信号中提炼"什么新增变量改变了市场预期"，附水下公司推导
- **周报生成**：选日期范围 → 生成周度市场认知报告 → 写回知识库（动态追踪分类）
- **公众号**：贴文章链接或正文 → AI 提炼信号（重要程度⚑ / 对行业认知的影响 / 相关水下公司）→ 你确认后入池

### 🔍 浏览与搜索

- 首页：按分类浏览 + 最近更新 + 本周 AI 花费
- 文档页：右侧栏本页目录、底部相关推荐、可用 VSCode 打开
- 侧栏「快捷入口」：本手册 + 项目解剖模板、产业链投资图谱等高频文档

## 推荐节奏

- 拿到新资料 → 归档（审核分类只要 30 秒）
- 读到好公众号文章 → 雷达「公众号」tab 贴进去
- 来新项目 → 归档 → 发起评审 → 发起 Battle
- 周五看一眼雷达周报

## 常见问题

- **分析要多久？** 单篇几秒到半分钟，后台跑，不用守着
- **手滑刷新/关了页面？** 任务进度实时落盘，回来看进度；真中断了会有提示，重新发起即可
- **AI 会瞎编吗？** 整理只基于原文，框架里原文没涉及的章节会标「（原文未涉及）」；信号的"水下公司"是 AI 推导，界面有标注，需人工核实
- **改错了怎么办？** 知识库就是一堆 .md 文件，直接改/删后点右上角「🔄 刷新」重建索引

## 给站主的备注（访问者可忽略）

- 所有访问者共用同一个知识库：任何人的入库、写回，大家都可见
- AI 调用走每个使用者自己在侧边栏填的 Moonshot API Key（只保存在本机 `data/local_api_key.txt`，不会上传）；站主在命令行直跑脚本（`radar_auto.py` 等）时，才会读环境变量 `MOONSHOT_API_KEY` 或 `~/.kimi/config.toml` 里的 key
- 分类定义、分类↔研究框架映射在 `config.py`，改完刷新索引生效
