# 项目深度解剖与IC报告提取模板（v2.0）

> 双重目标：
> 1. **决策**：回答"如果我现在要投/不投，我的决策依据是什么？"
> 2. **沉淀**：把每份 IC 报告转化为结构化投资知识资产，而不是被存档的 PDF。
>
> 提取分三层智能：**Company Intelligence**（这家公司是什么、为什么值得投）、**Industry Intelligence**（行业正在发生什么变化、价值如何分配）、**Comparative Intelligence**（相比同类项目和历史案例有什么不同）。
>
> 每条内容标注四类信息之一：**Company Fact**（公司事实）/ **Industry Fact**（产业事实）/ **Investment Thesis**（投资判断，是观点不是事实）/ **Monitoring Variable**（验证变量，供复盘用）。
>
> 回填去向：项目数据库 / 行业数据库 / Thesis 数据库 / 投资复盘。
>
> 分工：单项目解剖与 IC 报告提取 → 本模板；基金/GP 投决报告 → `03_frameworks/机构投资心智模型提取方法论.md`（成果归档至 `08_funds/`）；基金关键信息速查表 → `03_frameworks/投决报告结构化分析.md`。
>
> 原则：不复述公司业务，重点提取"为什么这个投资成立"；材料没有的信息标注 Not Available，不推测。

**投资机会**：投委会认为的核心机会来自哪类变化——市场变化 / 技术变化 / 用户需求变化 / 产业结构变化。

```
Investment Opportunity:
Why Now:

```

**完整投资链条**（每一环都要成立，环与环之间要必然）：

```
行业变化 → 市场机会 → 公司定位 → 竞争优势 → 价值实现
```

## 六、产业认知提取（Industry Intelligence，重点）

> 这一层是本模板的核心沉淀。公司会死，行业认知会留下来。
> 不回答"这个生意是什么"，而回答"这个行业正在发生什么、价值如何分配、为什么它会产生投资价值"。

### 6.1 行业为什么现在出现

- 过去限制：____
- 现在变化（技术/需求/成本/基建/政策）：____
- 变化机制与新机会：____

### 6.2 Industry Definition

- 行业 / 细分赛道：____
- 产业链位置：该公司处于产业链哪个环节？解决产业链中的什么问题？

### 6.3 Industry Evolution（产业演进）

- 过去：行业如何发展到今天：____
- 现在：当前处于什么阶段：____
- 未来：可能如何演进：____
- **产业范式变化识别**（如：硬件驱动→软件驱动；单点工具→平台生态）：____

|---|---|---|---|

| Capital Driver（资本推动） | | | |

### 6.5 Industry Bottleneck（核心瓶颈）

- 技术 / 商业化 / 供应链 / 成本 / 市场教育瓶颈：____

### 6.6 问题与需求

- 真实痛点 / 伪需求排查：____
- 旧方案与不足：____
- 切换动力：____

### 6.7 Value Chain（价值创造与捕获，核心）

- 上游（核心供应商）→ 中游（平台/产品/基础设施）→ 下游（客户与应用场景）：____

### 6.8 Industry Economics（行业经济模型）

- 收入模式 / 成本结构 / 毛利水平：____

- 壁垒与终局（垄断/寡头/生态竞争/高度分散）：____

### 6.9 关键假设与证伪条件

- 市场/技术/商业/竞争假设：____
