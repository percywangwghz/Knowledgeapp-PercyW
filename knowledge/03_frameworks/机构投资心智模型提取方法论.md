# 机构投资心智模型提取方法论（框架 v2.0）

> 用途：每阅读一家 GP 的 LP 投决文件、基金尽调材料、投资复盘，按本框架逆向提取该机构的**投资心智模型（Investment Mind Model）**。
> 目标：不是总结机构信息，而是回答——这家机构如何理解投资世界？它认为超额收益来自哪里？它如何发现机会、判断公司、做出下注？哪些判断逻辑值得学习和迁移？
> 输出标准：像"投资人的认知模型"，而不是"基金研究报告"。不复述材料，做方法论抽象；所有结论必须能迁移到其他行业和项目分析。
> 归档：每家机构一个文件（`序号_机构名.md`），统一放在 `08_funds/` 目录；本框架本身存放于 `03_frameworks/`。

## 一、信息过滤原则

**主动过滤**（除非直接体现投资决策逻辑，否则不提取）：

- 基金运营信息：规模、LP 结构、管理费、carry、期限、募资情况；
- 法律及交易信息：法律条款、投资协议、SPV 结构、交易安排、合规内容；
- 行政流程：内部审批、文件流程、非投资相关组织信息。

**重点保留**：投资理念、行业判断方式、公司筛选标准、投资决策逻辑、风险判断框架、成功案例背后的共同模式。

**四条校验原则**（防止被材料带偏）：

1. **策略-业绩一致性检验**：宣称的打法必须能在数据里找到痕迹。说一套做一套是重要的负面信号。
2. **归因拆解**：业绩 = 时代贝塔 + 资源禀赋 + 方法论阿尔法。前两者学不了，只有第三层值得吸收。
3. **警惕生存者偏差**：投决报告自带募资动机，GP 自己讲的故事要打折；重点看失败案例分布、剔除极值后的业绩。
4. **不推测**：材料没有的信息（尤其失败与盲区）标记 Not Available，不主动编造。

## 二、提取框架（九个模块 + 两个附录）

### 模块 1：核心投资哲学（Core Investment Philosophy）

不提取公开口号，从策略、案例、团队行为和决策方式中逆向推导第一性原理。回答：**该机构认为超额收益来自哪里？**

- Alpha 来源假设：信息优势 / 认知优势 / 时间优势 / 产业理解 / 网络资源 / 资本能力 / 其他？
- 世界观假设：它如何理解市场变化、产业演进、公司成长、竞争优势的形成？

产出 **Core Investment Belief**：一句话总结最底层投资信念。
（不写"关注早期科技"，要抽象为"认为早期阶段存在最大认知不对称，因此通过提前识别产业范式变化获得超额收益"。）

### 模块 2：机会识别框架（Opportunity Discovery Framework）

不提取具体行业，提取机会判断逻辑：

- Structural Change：关注哪类结构性变化（技术/产业/消费/政策/基础设施）；
- Timing Logic：为什么现在是窗口；
- Market Mispricing：市场当前错误理解在哪里；
- Value Migration：价值未来如何迁移。

产出 **Opportunity Formula**：如"技术突破 × 产业重构 × 市场认知差 = 投资机会"。

### 模块 3：超额收益来源（Source of Investment Edge）

为什么这家机构能持续获得比市场更好的机会？拆四类：Knowledge Edge（长期产业研究）/ Network Edge（创业者与产业资源）/ Pattern Recognition（历史案例积累）/ Decision Edge（流程与组织能力）。

**Sourcing 拆到动作层**（重点学习对象）：每条项目来源路径回答具体动作——行研怎么做（top-down 怎么拆产业链、是否遍历）、人脉怎么积累（EIR/活动/社区）、生态怎么反哺（被投供应链交叉验证）、各自占比与代表案例。不停留在"人脉广"这种废话。

产出 **Investment Edge**：真正不可复制的优势是什么。不写"团队优秀"，要解释团队能力**通过什么机制**转化为投资优势。

### 模块 4：行业研究方法（Industry Thinking Framework）

不描述研究流程，提炼面对未知行业的**思考顺序**：

- Industry Evolution：如何判断行业发展阶段；
- Key Variables：哪些变量决定行业未来；
- Value Chain：如何理解产业链价值分配；
- Winner Selection：如何判断未来赢家。

产出 **Industry Analysis Framework**：第一步判断 X → 第二步分析 X → 第三步寻找 X。

### 模块 5：公司判断体系（Company Judgment Model）

不简单罗列"团队、产品、市场"，提炼判断逻辑：

- Founder Judgment：它认为优秀创业者的本质是什么（行业认知/长期愿景/学习能力/组织能力/别的）；
- Product / Technology Judgment：如何判断产品与技术价值；
- Business Model Judgment：如何判断商业化潜力；
- Moat Formation：它认为壁垒如何形成。

产出 **Winner Definition**：该机构对"伟大公司"的定义。

### 模块 6：投资决策逻辑（Decision Framework）

在高度不确定下如何下注：什么决定投、什么决定不投。

- Key Decision Factors：最重要的决策变量；
- Risk-Reward Judgment：如何衡量风险与潜在收益（赔率结构：成功率 × 倍数 × 权重）；
- Uncertainty Management：如何处理信息不足；
- Conviction Building：如何形成高信念投资（含加注/超配机制）。

产出 **Decision Principle**：下注时遵循的核心原则。

### 模块 7：成功投资模式挖掘（Winning Pattern Mining）

不逐个总结成功案例，**寻找不同案例之间的共同结构**（如：技术突破→成本下降→市场扩张→平台形成）。案例证据从附录 A 的被投公司整理中来，此处只输出抽象后的 **Winning Pattern**。

### 模块 8：失败与认知边界（Blind Spot Analysis）

该机构在哪些情况下容易判断错误（技术/市场/商业化/竞争/时间判断）。材料无相关信息时标记 Not Available，不推测。组合层面的内在代价（如高核销率、集中度风险）也在此标注。

### 模块 9：最终心智模型（Final Investment Mind Model）

压缩为完整逻辑链：

```
该机构相信 X → 因此寻找 X → 通过 X → 判断 X → 最终下注 X
World View → Opportunity Definition → Research Framework → Company Judgment → Decision Framework → Investment Outcome
```

一句话总结该机构的投资体系。

### 附录 A：被投公司整理（认知的证据库）

报告中出现的每个被投/拟投公司建一条：公司-赛道-进入轮次-投资逻辑（为什么是它）-sourcing 路径-结果/现状。成功案例看打法，失败案例看风控。案例的作用是支撑模块 7 的模式挖掘和校验宣称策略，不是罗列 portfolio。

### 附录 B：负责人个体画像（核心资产）

每人一档：职业 MOC（注明是否剔除极值）、赛道、**能力禀赋**（他靠什么看到别人看不到的）、**认知框架**（他自己的决策公式/原话）、风格（激进/稳健、出手频率）、业绩验证。

## 四、核心要求

1. 不总结机构做了什么，而分析机构**为什么**这么做；
2. 不提取投资项目本身，而提取投资**判断逻辑**（案例仅作证据）；
3. 不复述材料，而进行方法论抽象；
4. 所有结论必须能够迁移到其他行业和项目分析；
5. 区分"能学的"与"学不了的"：依赖时代贝塔、资金规模、品牌网络的部分明确标注学不了，形式学不了的要追问内核是否可迁移。

## 五、横向累积

每新增一家，更新对比表，逐步形成自己的坐标系——重点看不同 GP 在相同问题上的分野（如：超额收益来自认知差 vs 来自赛道卡位；识人看"加速度" vs 看"过往战绩"）。

| 机构 | Core Belief（一句话） | Opportunity Formula | Investment Edge | 识人核心 | 已验证程度 |
|---|---|---|---|---|---|
| 五源资本 | 早期阶段存在最大认知不对称，提前识别范式变化获取超额收益 | 技术变量 × 范式变化 × 非共识定价 | 认知驱动行研 + 生态圈反哺 + 重仓超配 | 创始人的"加速度" | 美元已验证，人民币待验证 |
